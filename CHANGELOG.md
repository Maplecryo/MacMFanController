# Changelog

## 1.0.0 - 2026-10-11

- Added macOS menu bar fan control for Apple Silicon Macs through `smctl`.
- Added synced and independent fan controls.
- Added fan presets and manual RPM entry.
- Added live CPU Die and GPU Proximity temperature display.
- Added configurable GPU and CPU Die auto-trigger rules.
- Added one-click reset to automatic fan control.
